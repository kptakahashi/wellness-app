# Wellness app 設計メモ: 理想形と使用イメージ

## 一言で

自分で記録しない。推定されたものに Yes/No を返すだけで、1日3分で自分の調子の法則が見えてくるアプリ。

## 5層構造

| 層 | 役割 | ユーザーがやること |
|---|---|---|
| 収集 | デバイス、決済、カレンダー、位置、スマホ利用を自動で吸い上げる | 初回の連携のみ |
| 統合 | 全ソースを1本の「日次タイムライン」に時刻順で並べる | なし |
| 推定 | AI が食事内容、運動、ストレス区間、主観状態の仮説を立てる | なし |
| 確認 | 朝30秒の音声、夜2分のカード確認、日中は最大1〜2回の1タップ質問 | Yes/No と一言 |
| 洞察 | 事実だけを提示する。指示はしない。聞かれたら提案する | 読む。気になれば質問する |

## 取りたい情報と、採用したチャンネル

### 睡眠・生体データ
- ◎ Health Connect(RingConn、Oura、Garmin、Pixel/Galaxy Watch が書き込む OS のハブ)
- △ 各デバイスの公式 API(RingConn は公開 API なし。ハブ経由なら不要)

### 食事
- ◎ 決済通知(通知リスナー): PayPay、カード会社アプリ、マネーフォワードの「新着の入出金」。店名・金額・時刻
- ◎ カレンダーの会食予定: 店名と参加人数 → まとめ払いの按分根拠
- ○ 位置情報の飲食店滞在: 決済がない場合の補完
- ○ Uber Eats 等の注文メール: 品目まで取れる
- ○ 音声で一言: 自炊・現金払いの救済

### 運動
- ◎ Health Connect のワークアウト記録(時計の自動検出)
- ◎ 心拍の上昇区間
- ◎ カレンダーのジム予定 + 位置情報のジム滞在
- ◎ 歩数
- 登録済みの「いつもの運動」と一致すれば質問すら省略

### ストレス・稼働
- ◎ HRV、安静時心拍
- ◎ カレンダーの会議密度
- ◎ Android の使用状況統計(どのアプリを何分、深夜利用)
- △ iPhone のスクリーンタイム(外部に出せない。iPhone 版は自己申告に縮退)
- ○ 夜の確認での 3段階ストレス

## 主観状態の取り方(タイミング設計)

- 朝: 起床を睡眠データで検知 → 「睡眠6時間20分、HRV やや低め。体感は?」に音声で一言
- 夜: 決まった時刻に推定カード 5枚前後。Yes/No。最後に「今日の調子 1〜5」
- 日中: 原則 1日1回まで。食後30〜60分の心拍変化、スマホ長時間利用の直後など、聞く価値がある瞬間だけ 3択
- 週次: 日曜夜 5分。事実カードを読む

## 洞察の出し方

指示はしない。出すのは事実・相関・確からしさだけ。

- 「ラーメンを食べた日の午後は、ほかの日より HRV が平均12%低い。今月4回中4回」
- 「ジムに行った日の翌朝は、入眠までの時間が平均15分短い」

「じゃあどうすれば」と聞かれた時だけ、「来週1回、昼のラーメンを別のものにして午後の HRV を比べてみる」と実験の形で返す。N=1 の自己実験プラットフォーム。

## 1か月の使用イメージ

### 初日(30分)
Health Connect、Google カレンダー、通知、位置の連携。「いつもの運動」「いつもの朝食」を登録。朝と夜の通知時刻を決める。

### 1週目: 学習期間
カードが8枚くらい出る。「セブンで480円。おにぎりとコーヒー?」に「おにぎりとサラダ」と訂正する日が続く。洞察はまだ出さない(サンプル4日で言われると信用が崩れる)。

### 2週目: 静かになる
「いつものコンビニ朝食」「火曜14時の定例」「水曜夜のジム」を覚え、カードは4〜5枚。訂正はほぼなくなる。週末に「まだ確度は低いですが」付きの傾向が1〜2枚。

### ある平日(3週目)
- 7:05 起床検知。「睡眠6時間50分、深い睡眠は多め。体感は?」→ 音声「わりとすっきり」
- 日中は通知なし。裏で決済2件、会議4件、歩数3,200歩が溜まる
- 14:40 1件だけ。「12:30 の食事から2時間、心拍が平常より低め。眠気は?」→「ある」
- 22:30 カード5枚。「12:30 ○○で1,050円、カツカレー?」Yes。「16:00〜17:30 の連続会議、ストレスは?」中。「今日の調子は」3。合計90秒

### 4週目: 初めて意味のある事実
「午後に眠気を報告した日の昼食は、7回中6回が丼・麺類」「HRV が高かった上位5日はすべて前夜のスマホ利用が45分以下」。ここで「昼を変えたらどうなる」と聞けば2週間の比較実験を提案する。聞かなければ事実を知るだけで終わる。

### 1か月の累計コスト
朝30秒、夜2分、日中タップ1回、週次5分。1日約3分、月に1時間半。手で書いた記録はゼロ。
